### Svelte 5 runes 编译 Bug 修复
- **问题**: `$state is not defined` 运行时错误。Svelte 编译器未转换 rune 语法。
- **根因**: Svelte 5 不再支持 `compilerOptions: { runes: true }` 的嵌套写法，必须用顶层 `runes: true`。
  - `svelte.config.mjs`: `compilerOptions: { runes: true }` → `runes: true`
  - `vite.config.ts`: 移除重复 `compilerOptions`，仅靠 `svelte.config.mjs`
- **第二个问题**: `src/lib/stores/toast.ts` 使用了 `$state([])` rune，但 `.ts` 文件不会被 Svelte 编译器处理。Svelte 5 要求含 rune 的 TS 文件使用 `.svelte.ts` 扩展名。
  - `toast.ts` → `toast.svelte.ts`
  - `ToastContainer.svelte` import 路径同步更新
- **验证**: `$state(` 在 bundle 中出现次数: 4 → 1 → 0。构建通过 (50.36 kB)，5/5 测试通过。
