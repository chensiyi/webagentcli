### Svelte 5 迁移 — 修复 ChatPage 输入区域未底部对齐

**问题**: ChatPage 的 `.chat-page` 高度只有 ~411px，没有撑满侧边栏高度，导致输入区域 footer 没有真正贴底。

**根本原因**: `App.svelte` 中 `.content-area` 设置为 `overflow-y: auto` 且不是 flex 容器，`.page-wrapper` 也没有 `height: 100%`，所以 `.chat-page` 的 `height: 100%` 只能相对于内容高度生效。

**修复文件**: `src/App.svelte`
- `.content-area`: 改为 `display: flex; flex-direction: column;`，移除 `overflow-y: auto`
- `.page-wrapper`: 改为 `flex: 1; min-height: 0; display: flex; flex-direction: column`

**辅助修复**: `src/pages/ChatPage.svelte`
- `.chat-input-area`: 保留 `display: flex; flex-direction: column`，让 footer 内部按列排列
- `.chat-input-row`: 保留 `align-items: flex-end`，多行文本时按钮贴底

**构建结果**:
- dist/svelte-app.bundle.js 108.14 kB
- dist/assets/svelte-app.css 42.20 kB
- 206 modules, 0 warnings ✅
- 缺失功能清单
- 实施计划和建议优先级

### 2. SettingsPage 模型选择

**问题**: 用户反馈"填充的内容有问题，也没有下拉框"。

**根因**:
- `selectModel()` 把 `modelSearchValue` 设为 model ID，导致输入框显示原始 ID 而非模型名称
- 点击输入框时 `handleModelSearchClick()` 是 toggle 行为，可能刚打开就关闭

**修复**:
- `src/pages/SettingsPage.svelte`
  - `selectModel()` 中改为 `modelSearchValue = ''`，让输入框显示 `selectedModelName`
  - `handleModelSearchClick()` 改为总是打开下拉框（`showModelDropdown = true`）
  - 为模型输入框添加 `onfocus={handleModelSearchClick}`，focus 时自动展开下拉
- `src/components/ui/Input.svelte`
  - 新增 `onfocus?: (e: FocusEvent) => void` prop 并转发到 `<input>`
- 补充 `aria-selected` 到模型列表项，消除 a11y 警告
