# Web Agent Client — UI 设计总览

**设计日期**: 2026-07-01  
**设计师**: UI Designer  
**设计上下文**: Chrome MV3 Sidebar 扩展（~400px 宽视口），面向开发者的 AI Agent 对话工具

---

## 设计系统

| 维度 | 规范 |
|------|------|
| **主色** | Blue #378ADD（原 #1976d2 → 更现代的蓝色） |
| **字体** | System sans-serif（-apple-system, BlinkMacSystemFont） + Consolas 等宽 |
| **圆角** | 8px（卡片/输入框）、12px（气泡）、999px（胶囊按钮） |
| **边框** | 0.5px solid，三级透明度分层 |
| **间距** | 4px 基础单位（8/12/16/20/24） |
| **深色模式** | 完整支持，通过 CSS 变量切换 |
| **可访问性** | WCAG AA 色彩对比度达标 |

## 五页面设计

### 1. ChatPage 对话页面

**核心组件**: 消息气泡（用户右对齐蓝底 / AI 左对齐灰底）、代码块、思考过程折叠区、工具调用卡片（左侧 3px 色条）、工具结果卡片、输入区+发送按钮、工具标签切换

**交互状态**:
- 流式响应时发送按钮切换为停止按钮
- 消息 hover 显示删除按钮
- 思考过程可展开/折叠
- 工具调用运行时显示脉冲动画状态点

### 2. HistoryPage 历史对话

**核心组件**: 搜索框（带图标）、时间分组标签（今天/昨天/更早）、对话卡片（智能标题、消息数、时间、Provider 标签、删除按钮）、底部分页

**交互**:
- 点击卡片加载对应对话并跳转到 ChatPage
- 删除需确认（Toast 对话框）
- 搜索实时过滤（500ms 防抖）

### 3. StoragePage 存储管理

**核心组件**: 统计卡片（存储项/总大小/会话数）、搜索框、存储项列表（等宽 Key、类型、大小、日期）、编辑/删除操作、异常项红色高亮

**交互**:
- 点击编辑弹出 CodeMirror JSON 编辑器
- 删除需确认
- 分页浏览（20 条/页）

### 4. ScriptsPage 脚本管理

**核心组件**: 脚本卡片（名称、描述、版本、启用状态标签）、编辑/删除按钮、安装新脚本入口

**状态展示**:
- 已启用: 绿色标签 + 全不透明度
- 已禁用: 灰色标签 + 60% 不透明度
- 空状态: 引导安装提示

### 5. SettingsPage 设置

**核心组件**: API 标准三选一（OpenAI / OpenRouter / LM Studio Tab 按钮）、Provider 配置区（API Key 密码输入+显示切换、Endpoint、Temperature 滑块、Max Tokens、System Prompt）、模型选择下拉搜索、上下文管理（最大消息数、思考强度）、深色主题开关、保存/重置按钮

## 设计决策

| 决策 | 理由 |
|------|------|
| 侧边栏在右侧 | 保持主内容区不受干扰，Chrome Sidebar 天然右附着 |
| 胶囊按钮 (pill) | 节省空间、明确可点击、统一形态仅切换配色 |
| 3px 左侧色条 (status-card) | 快速传达工具调用/结果的状态语义 |
| 用户消息蓝底右对齐 | 符合聊天 UI 惯例，视觉区分对话双方 |
| 原子化 CSS 组合 | pill + status-card + panel-surface 三原子上构建所有组件，避免样式重复 |
